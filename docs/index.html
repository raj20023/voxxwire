Under the Hood

How It Works

01

Audio Capture

Captures your microphone and system audio streams in real time using low-latency audio drivers.

02

Voice Activity Detection

Silero VAD detects when someone is speaking and segments the audio into utterances, filtering silence.

03

Speech Recognition

OpenAI's Whisper model (via faster-whisper) transcribes the spoken audio into text with high accuracy.

04

Translation

Argos Translate converts the transcribed text from the source language to your target language, entirely offline.

05

Output

The translated text is displayed as live subtitles and spoken aloud through Piper TTS voices.

FAQ

Frequently Asked Questions

Is Voxxwire really free?

Yes — completely free and open source. No subscriptions, no API keys, no hidden costs. Download once and use it forever.

Does Voxxwire need an internet connection?

No. Speech recognition (Whisper), translation (Argos Translate), and text-to-speech (Piper) all run locally on your machine. The app only touches the network to download a language pack the first time you use a new language pair.

Is any of my audio or conversation data sent anywhere?

No. Everything is processed locally in memory. Nothing is uploaded, logged remotely, or shared with any third party.

Do I need an NVIDIA GPU?

No, a GPU is optional. Voxxwire runs on CPU too — a GPU just makes transcription and translation noticeably faster, especially with the larger Whisper models.

Why does Windows show a "protected your PC" warning?

Voxxwire doesn't yet have a paid code-signing certificate, so SmartScreen flags it by default. The app is fully open source — you're welcome to review the code on GitHub. Click "More info" → "Run anyway" to continue.

Which apps does Voxxwire work with?

Any app that plays audio through your system output — Zoom, Google Meet, Microsoft Teams, Discord, YouTube, and more — since Voxxwire captures system audio directly rather than integrating with a specific app.

Is Voxxwire open source?

Yes. The full source is on GitHub — issues, pull requests, and contributions are welcome.
